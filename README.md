<p align="center">Java 17 · Servlet · JSP · JDBC · Oracle · Tomcat 9</p>

## 프로젝트 소개

POPFLIX는 영화 정보를 확인하고 상영 일정과 좌석을 선택해 예매한 뒤, 리뷰와 필름 다이어리로 관람 경험을 남기는 웹 서비스입니다.

Servlet·JSP 기반 **MVC2 구조**로 요청 처리, 업무 로직, 데이터 접근과 화면을 분리했습니다. 예매·좌석처럼 함께 변경되어야 하는 데이터의 트랜잭션 처리와 로그인 사용자별 접근 범위를 구현하며 Java 웹 서비스의 전체 흐름을 학습했습니다.

## 내가 구현한 예매 흐름

```text
영화 선택 → 영화관·상영 일정 선택 → 좌석 조회·선택
                                      ↓
                             로그인·입력값 확인
                                      ↓
                     상영 일정·좌석 소속·기존 예매 검사
                                      ↓
                       예매 정보와 선택 좌석 함께 저장
                                      ↓
                          예매 완료 → 필름 다이어리 연동
                                      ↓
                      내 예매 목록·상세 → 좌석 변경 / 취소
```

### 1. 예매와 좌석 정보를 하나의 트랜잭션으로 저장

예매 정보만 저장되고 좌석 정보가 누락되면 목록과 좌석 현황이 달라집니다. `ReservationService.reserve()`에서 하나의 JDBC 연결을 사용해 자동 커밋을 끄고, 예매 대표 정보와 선택 좌석을 함께 저장했습니다. 모두 성공하면 커밋하고 중간에 실패하면 롤백합니다.

저장 전에는 상영 일정의 존재 여부, 최소 한 개 이상의 좌석 선택, 좌석이 해당 상영관에 속하는지, 이미 예매된 좌석인지를 확인합니다.

> 필름 다이어리 생성은 예매 저장 성공 후 Servlet에서 별도로 호출합니다. 예매·좌석 저장과 동일한 트랜잭션에 포함되지는 않습니다.

### 2. 좌석 변경과 예매 취소의 일관성

좌석 변경은 기존 좌석 삭제 → 새 좌석 등록 → 인원수 갱신을 하나의 트랜잭션으로 묶었습니다. 중복 검사에서는 현재 예매의 좌석을 제외해 기존 좌석을 유지하면서 변경할 수 있도록 했습니다.

취소는 좌석 점유 데이터 삭제와 예매 상태 변경을 함께 처리합니다. 취소한 좌석은 다시 선택할 수 있고 예매 내역은 상태값으로 관리합니다.

### 3. 로그인한 사용자의 예매만 조회·변경

예매 번호만으로 요청을 처리하지 않고 로그인 회원의 식별자를 함께 전달합니다. 상세 조회·변경·취소 시 해당 회원의 예매인지 확인하고, 변경과 취소는 활성 예매에 한해 수행합니다.

관련 코드: [ReservationService](src/main/java/reservation/service/ReservationService.java) · [ReservationInsertServlet](src/main/java/reservation/controller/ReservationInsertServlet.java) · [ReservationDAO](src/main/java/reservation/dao/ReservationDAO.java)

## 팀 서비스의 주요 구현

- **영화 정보 연동:** KMDb 검색·상세 응답을 DTO로 가공하고 DB에 저장해 반복 조회에서 활용합니다.
- **리뷰 공개 범위:** 친구 관계와 공개 설정을 기준으로 다른 사용자가 볼 수 있는 리뷰를 구분합니다.
- **관람 기록:** 예매와 연결한 다이어리에 감정 태그·팝콘 평점을 기록하고 달력·통계 화면으로 제공합니다.
- **관리자 접근:** 필터에서 로그인 상태와 DB의 최신 회원 상태·관리자 권한을 확인합니다.

## 실행 방법

이 저장소는 Maven·Gradle 프로젝트가 아닌 **Eclipse Dynamic Web Project**입니다.

1. JDK 17, Eclipse Enterprise Java 환경, Apache Tomcat 9.0, Oracle DB를 준비합니다.
2. 저장소를 복제하고 Eclipse의 `Existing Projects into Workspace`로 가져옵니다.
3. 프로젝트 런타임을 Tomcat 9.0으로 지정합니다.
4. `.classpath`에서 참조하는 라이브러리를 `src/main/webapp/WEB-INF/lib/`에 준비합니다: `gson-2.11.0.jar`, `json-20230618.jar`, `jstl-1.2.jar`, `ojdbc8.jar`.
5. 프로젝트 DB 스키마와 초기 데이터를 별도로 준비하고, `common/DBUtil.java`의 연결 설정을 로컬 Oracle 환경에 맞춥니다.
6. KMDb·네이버 로그인 연동 설정을 본인 애플리케이션의 값으로 구성합니다. 로그인 콜백 주소도 실행 환경과 일치시킵니다.
7. Tomcat에 프로젝트를 추가한 뒤 `http://localhost:8080/<context-path>/main.do`로 접속합니다. `<context-path>`는 Eclipse에 설정된 프로젝트 경로입니다.

현재 저장소에는 DB 초기화 SQL과 참조 JAR가 포함되어 있지 않으므로 별도 준비가 필요합니다. 실제 DB 계정·API 인증 값은 공개 저장소에 올리지 않습니다.

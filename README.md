# POPFLIX

영화 예매 및 리뷰 서비스입니다.

[포트폴리오 홈](https://github.com/jeonggul) · [팀 저장소](https://github.com/Rustapex/JavaServletMVC-Project)

## 프로젝트 개요

**기간:** 2026.04.29–2026.05.14  
**구성:** 5인 팀 프로젝트

영화 조회와 좌석 예매에 리뷰·친구·필름 다이어리를 연결한 웹 서비스입니다. Servlet과 JSP 기반 MVC 구조에서 예매 요청과 데이터 처리를 분리했습니다.

## 담당 범위

조장 및 예매 기능 담당. 영화관·상영관과 좌석 선택, 예매 등록, 본인 예매 조회·변경·취소를 구현했습니다. 마이페이지를 포함한 공통 스타일·화면 통합과 병합 충돌 정리에도 참여했습니다.

아래 내용은 제가 담당한 예매 기능을 중심으로 정리했습니다.

## 사용 기술

Java · Servlet · JSP · JDBC · Oracle · HTML · CSS · JavaScript · Git/GitHub

## 예매 정보와 좌석 정보의 일관성

예매와 선택 좌석을 따로 저장하다 중간에 실패하면 일부 데이터만 남을 수 있습니다. 하나의 연결에서 예매와 좌석 정보를 함께 처리하고, 실패 시 전체를 롤백하도록 구성했습니다. 요청한 좌석이 해당 상영관에 속하는지와 이미 예매된 좌석인지도 저장 전에 확인했습니다.

## 변경과 취소의 처리 범위

좌석 변경은 기존 좌석 삭제, 새 좌석 등록, 인원수 갱신을 하나의 트랜잭션으로 묶었습니다. 취소는 좌석 점유 해제와 예매 상태 변경을 함께 처리했습니다. 로그인한 사용자의 예매인지 확인해 다른 사람의 예매를 변경하거나 취소하지 못하도록 했습니다.

## 화면과 요청 처리

예매 화면에서는 영화관·상영관과 좌석을 선택하고 결과를 확인합니다. 본인 예매 목록과 상세 조회를 통해 변경·취소로 이어집니다. 좌석 조회와 요청 처리를 Servlet, 서비스, DAO로 분리해 화면과 DB 처리의 책임을 나누었습니다.

## 개발 환경

Java · Servlet/JSP · JDBC · Oracle 기반 웹 프로젝트입니다. 실행하려면 Servlet 컨테이너, Oracle 데이터베이스와 프로젝트에 맞는 DB 연결 설정 및 스키마가 필요합니다.

이 문서는 개인 담당 기능과 구현 경험을 정리한 포트폴리오입니다. 현재 저장소의 실행 환경을 새로 구성하거나 테스트를 재실행한 결과를 의미하지 않습니다.
